# Samples

Only **sanitized synthetic or laboratory output** may be stored here.

Never add real customer discovery output.

Before committing a sample, remove or replace:

- customer/domain names;
- public/private addresses that identify a real environment;
- usernames;
- serial numbers;
- software identifiers tied to a customer;
- secrets or credentials;
- any business-sensitive naming.

Samples should exist to test parsers, schemas and documentation — not to archive
assessment evidence.
